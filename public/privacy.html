nycbot privacy policy

nycbot is a personal assistant used only by its owner, Yong Tay.

With the owner's permission it reads and edits the owner's Google Calendar events to send daily agendas and create events the owner requests.

Calendar data is not sold, shared with third parties, or used for advertising. It is processed only to provide these features and is not stored beyond what the features need.

Access can be revoked at any time at https://myaccount.google.com/permissions.
